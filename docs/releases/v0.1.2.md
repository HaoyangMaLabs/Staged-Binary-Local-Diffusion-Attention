# v0.1.2 — Updated manuscript and paired accuracy experiments

Updates the English manuscript and root `paper_en.pdf` to include paired three-seed PG-19 book and repository-disjoint Python accuracy experiments. SBDA improves the tested book results but performs worse on the Python subset; the fixed twenty-pass budgets do not establish convergence.

Adds the recorded twenty-layer million-position forward benchmark, separating attention-interaction kernel time (476.58× speedup) from backbone wall time (56.01× speedup). The backbone measurement excludes the vocabulary head, backward pass and optimizer.

Includes all 118 source experiment record files, including 28 logs, plus the corresponding protocols and reproduction scripts. Updates README results, PDF export and artifact checksums. Video scripts are excluded.

Validation: all source experiment records match byte for byte; all 26 manuscript artifact paths resolve; the 13-page English PDF contains the correct author and email. Regression tests: 31 passed, one GPU test skipped. Large training experiments were not rerun.
