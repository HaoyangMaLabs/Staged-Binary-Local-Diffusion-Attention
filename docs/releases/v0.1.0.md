# v0.1.0 — Paper and reproducibility release

This release archives the English manuscript and the code and recorded experiments for Staged Binary-Local Diffusion Attention.

- Author: HaoyangMa (haoyang@haoyangma.com).
- Includes `paper_en.md` and `paper_en.pdf`, figures, model implementation, and reproduction drivers.
- Preserves dataset splits, original JSON/CSV results, and all five experiment logs.
- Adds shared topology, dataset and comparison modules, CPU smoke support, regression tests, and a locked environment.
- Provides Zenodo metadata and GitHub citation metadata.

Validation recorded during cleanup: 31 tests passed, one fused BF16 GPU test skipped; 108 topology rows matched the original scanner; CPU smoke losses remained unchanged. The paper's large CUDA training runs were not repeated during cleanup.

The code is MIT licensed. Included datasets retain their upstream terms. See the README and paper Appendix B for environment requirements and reproduction commands.
